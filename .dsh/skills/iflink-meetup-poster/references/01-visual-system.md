# 01 · 视觉体系反拆（坐标级）

> 对象：`assets/reference/final-poster.png`，1024×1536 px，比例 2:3。
> 全部数值以 **1024×1536 为基准**，放大到 1536×2304 时等比 ×1.5。
> 测量方式：像素级行/列投影 + 区域取模色（见 `scripts/check-palette.py --debug`）。

## 一、色彩体系（三主色 + 三辅助色）

| 角色 | HEX | 实测值 | 面积占比 | 承载什么 |
| --- | --- | --- | --- | --- |
| 画布 / 基底 | `#F6F6F1` | `#F6F6F1 ~ #F7F7F2` | **69%** | 整张纸；略带暖调的奶油白，不是纯白 |
| 墨色 / 基底 | `#242021` | `#1D1C1E ~ #212120` | **10.9%** | 所有文字、描边、副标题色块、头像线稿 |
| 品牌荧光绿 | `#B1FA63` | `#B8EC67`（成图实测） | **9.3%** | 标题带、区块标、姓名 chip、图标、速度线、笔刷块、点缀角色阴影 |
| 白 | `#FFFFFF` | — | ≤3% | 副标题反白字、杯子、头像衬底 |
| 点缀色（二选一） | `#FE7733` 暖橙 / `#B2A1FF` 淡紫 | — | ≤6% | 只落在点缀角色/道具与 2–3 个小涂鸦；由模型按本期气质挑一个 |
| 极浅绿 | `#DCEFC0` | — | <1% | 嘉宾条目之间的分隔线、底部 sparkle |

### 配比公式

```
奶油白 65–75%  ＋  墨色 8–12%  ＋  荧光绿 8–12%  ＋  点缀色 ≤6%  ＋  白 ≤3%
```

> **7 : 1 : 1** 的观感比例。绿一旦超过 ~15%，就从"点睛"变成"糊墙"，整张会土。
> 荧光绿**只做块面和图标，不做长段文字**；小字用绿必死（对比度不足）。

### 点缀色的分寸（有意为之的"一点点异色"）

整张不用死守荧光绿。原作定稿实测里有 **3.0% 的暖黄**（右下角那只小奶龙），正是这一点异色让画面不发闷。
规则只有三条：

1. **只准一种**：出现第二种非品牌色就变"配色脏"。
2. **面积 ≤6%**：只落在点缀角色/道具与 2–3 个小涂鸦上，不碰任何文字与色块。
3. **最好来自内容**：比如那期有位嘉宾讲「如何成为一只会做推送的奶龙」，暖黄就是从话题里长出来的 —— 有出处的颜色才不显得随意。

> `#FE7733` 就在色板里 —— 当年它是"整版照抄参考图"的元凶，现在只在点缀位上合法：≤6%、不许铺成主色。

### 颜色承载规则（易错点）

- 主标题：**绿色块 + 墨黑字**（不是绿字）。
- 副标题：**墨黑色块 + 白字**（不是黑字压白底）。
- 嘉宾姓名：**绿块 + 黑字**，小圆角 chip。
- 正文：一律墨黑，字重 500，不用灰色（全图无中性灰，这是"高级"的关键）。

### 禁用

色板外的任何彩色（第三种颜色）、把暖橙/淡紫铺成主色或压在文字上、任何渐变、任何投影光晕、任何金属/霓虹/赛博/3D、任何灰阶文字。

## 二、版式：风格锁 + 版面库（**不要锁死分区**）

> 这是 Skill 最重要的一条原则。以前把「左信息 / 右插画」写成了硬坐标，结果每期长得一模一样，很死板。
> 现在拆成两层：**视觉语言锁死（色彩 / 字体层级 / 图形语言 / 留白节奏）**，**版面完全放开**。
> 参考图只提供"干净、利落的手绘风"这一层质感，**不提供分区** —— 左文右图只是其中一种排法，反过来、上下分、网格都成立。

### 2.1 为什么可以换版面

系列感来自这四样，不来自分区：

| 锁死的东西 | 为什么它决定"一眼是同一套" |
| --- | --- |
| 三主色 + 单一点缀色 | 颜色是最强的品牌识别 |
| 绿块压黑字 / 黑块压白字 的**色块标题语法** | 这是全系列唯一的"签名式"结构 |
| 字号层级（按画布高度百分比） | 保证任何版面下阅读节奏一致 |
| 手绘线稿 + 4–5px 粗描边 + 笔刷/速度线 | 质感指纹 |

只要这四样在，版面怎么摆都还是 IF.Link。

### 2.2 五套版面

| 代号 | 名称 | 构图 | 适合 | auto 触发 |
| --- | --- | --- | --- | --- |
| A | 左文右图 | 左 50–55% 信息，右 45–50% 插画 | 3–4 位嘉宾，最稳 | 3–4 位 |
| B | 上图下文 | 上 45–55% 整宽插画带，下方两列嘉宾网格 | 5 位、信息量大 | 5 位 |
| C | 中间插画横带 | 标题 / 横带插画 / 信息 三段式 | 2–3 位、要松弛感 | — |
| D | 大图主角 | 插画铺满，信息以奶油白实心块叠在图上 | 1–2 位、主题强 | ≤2 位 |
| E | 网格卡片 | 2×2 / 2×3 嘉宾卡片，插画缩到角落 | 4–6 位、强调阵容 | ≥6 位或无插画 |

**auto 规则**：无插画 → E；≤2 位 → D；3–4 位 → A；5 位 → B；≥6 位 → E。

> 系列一致性建议：**同一季固定一种版面**，别每期换。想换就整季换，或者只在特殊场次（周年、大咖场）用 D。

### 对齐纪律

| 规则 | 数值 |
| --- | --- |
| 左侧基准线 | **x = 54**（5.27%），仅 A 版：页眉、标题带、正文、嘉宾头像咬死这一条线 |

| 嘉宾条目节距 | 随人数三档：2 位 ≥180（头像 112）／3–4 位 140–190（头像 96）／5–6 位 110–140（头像 76） |

### 视觉动线

```
Logo ─→ 绿标题带（第 1 落点）─→ 黑副标题（第 2 落点）─→ 主张 ─→ 时间地点
                                                              ↓
              点缀角色（情绪收尾）←─ 福利笔刷 ←─ 嘉宾列表（扫码式纵向阅读）
                                                              ↕
                                              右侧插画（叙事锚点，长停留）
```

## 三、字体层级

| 层级 | 用途 | 字号 | 字重 | 行高 | 字距 | 字体族 |
| --- | --- | --- | --- | --- | --- | --- |
| L0 | 页眉 Logo | h 33 | 定制图形 | — | — | 官方 SVG，禁止字体模拟 |
| L0.5 | 页眉 slogan | 30 | 700 | 1.2 | -0.01em | Inter / 同族无衬线 |
| L1 | 主标题 | **110** | **900** | 0.92 | -0.03em | Inter Display / Google Sans 同族 |
| L2 | 副标题 | **64** | 800 | 1.05 | 0.02em | 中文思源黑体 Heavy + 西文 Inter Bold |
| L3 | 区块标题 | **38** | 800 | 1.2 | 0 | 思源黑体 Bold |
| L3.5 | 一句话主张 | **34** | 500 | 1.4 | 0 | 思源黑体 Medium |
| L4 | 嘉宾姓名 | **30** | 800 | 1.2 | 0 | 思源黑体 Bold |
| L5 | 嘉宾话题 | **27** | 500 | 1.5 | 0 | 思源黑体 Regular |
| L6 | 时间地点 | **26** | 700（值）/ 500（标签） | 1.4 | 0 | Inter + 思源黑体 |
| L7 | 福利标题 / 副句 | 42 / 30 | 900 / 700 | 1.1 | 0 | 手写感粗黑 |

**字体族锚点**（品牌规范同源）：

- 中文：**思源黑体**（Source Han Sans SC），Heavy / Bold / Medium / Regular
- 西文数字：**Inter**（Variable），Black / Bold / Medium
- 等宽（极少用）：JetBrains Mono
- Logo：Google Sans Flex（官方 SVG，**不可字体模拟**）

**禁止**：任何衬线体、任何书法体、同一张图出现两种以上中文黑体家族、正文加粗到 800 以上。

## 四、图形语言（"手绘线稿 + 粗黑块"的配方）

| 元素 | 规格 |
| --- | --- |
| 色块 | **直角矩形**，无圆角、无描边、无投影。标题带 / 副标题带 / 区块标全是直角 |
| Chip | 姓名 chip 圆角 **8–10 px**，绿底黑字，内边距 8×12 |
| 图标 | 32–36 px 绿底圆角小方块（圆角 6），内部墨色细线图形（日历 / 地标），线宽 2 |
| 插画描边 | 统一 **4–5 px 纯黑**，手绘抖动感，线条收口略圆 |
| 头像 | 直径 **96**，外圈 2.5 px 墨色圆环，内部白底 + 线稿半身像，**绿色只用于衣服** |
| 分隔线 | 1 px `#DCEFC0`，只跨文字列（x 186→500），不跨头像 |
| 笔刷块 | 边缘毛糙的手绘马克笔块，用于"小福利"标题底与点缀角色阴影 |
| 速度线 | 3 条短斜线，绿或墨，用于 "LET'S MEET!" 旁 |
| 手写涂鸦 | "LET'S MEET!" 旋转 -12°，"Hi!" 绿色手写，sparkle 用四角星 |
| 整体质感 | 印刷颗粒 + 轻微错位（misregistration），无高光、无渐变、无阴影 |

## 五、插画规范（右侧叙事区）

**场景**：4 位年轻人围坐（2 男 2 女），中间白板写着 `IF.Link Meetup`，桌上一台笔记本电脑 + 若干奶茶杯，白板旁有手绘速度线。

| 约束 | 取值 |
| --- | --- |
| 位置 | x 545→1010，y 615→1215 |
| 白板 | 绿色边框 + 白板面，微微倾斜 2–3°，内写两行 `IF.Link` / `Meetup` |
| 人物数量 | 与嘉宾数一致（4 位），且 **性别构成与嘉宾表一致** |
| 服装 | 主体白 / 墨黑，**每人一处荧光绿**（卫衣、帽子、袖口） |
| 表情 | 微笑、张口交谈，不画五官细节（点眼 + 弧嘴） |
| 禁止 | 写实人脸、照片质感、3D 渲染、复杂背景、渐变肤色 |

## 六、点缀角色规范（原作的黄色小奶龙）

> **这不是品牌吉祥物。** IF.Link 没有吉祥物；那只黄色小奶龙是**从罗丽老师的话题「如何成为一只会做推送的奶龙」里长出来的**，属于"这一期内容的可视化"，下一期可能完全不存在。

| 约束 | 取值 |
| --- | --- |
| 是否需要 | **默认不需要**。`decor.preset = none` 时右下角留白 + 2–3 个涂鸦即可 |
| 取材来源 | `topic`：某位嘉宾的分享标题；`custom`：用户直接描述 |
| 体型 | 圆润，头身一体，**无脖子**，宽度 > 高度；4–5 px 墨黑描边，圆角收口 |
| 配色 | 主色是**点缀色**（原作 `#FED754`，不是荧光绿 —— 原作曾被打回两次） |
| 五官 | 一只黑豆眼（带白色高光点）+ 一只 `>` 形笑眼 + 一个橙色小嘴（可选） |
| 道具 | 与主题相关即可（原作是白色纸杯竖排 `IF.Link` + 吸管） |
| 姿态 | 坐姿，双手自然摆放或捧道具 |
| 底衬 | 绿色笔刷水洼（不规则边缘），把角色"按"在画面上 |
| 旁饰 | 绿色手写拟声词（原作 "Hi!"）+ 一段 `C` 形涂鸦 |
| 位置 | x 620→1000，y 1230→1520（可压出下边距） |

**判据**：如果换一场活动，观众看不出这个角色和本期内容有什么关系，那就不该画它。

## 七、与品牌规范的对齐检查

| 品牌规范条款 | 本海报的落实 |
| --- | --- |
| `IF.` 粗体、`Link` 细体，但作为 logo 字号一致 | 页眉仅用官方 SVG，不重绘 |
| 深 / 浅背景用对应 Logo 版本 | 奶油白底 → 用**浅色背景版（黑字）** |
| 优先 SVG | `assets/reference/*.svg` |
| Logo 是定制图形，不可字体模拟 | 页眉为图形；仅正文出现 `IF.Link` 字符串时用系统字体直打 |
| 禁衬线，只用无衬线或 mono | 全图无衬线 |
| 大小写 `IF.Link` / `IF.Land` | 全图统一 `IF.Link`；slogan 的 `IFs` 复数、`Dots` 大写 |
| Slogan 逐字 `Link the IFs, Connect the Dots` | 无结尾句号；品牌库旧图（小写 `dots.`）不作为标准，规范版图由 `make-slogan.py` 生成 |
| 蓝底大文本勿用黑 | 本系列无蓝底；深黑灰底上的大文本用**白字**（同原理） |
