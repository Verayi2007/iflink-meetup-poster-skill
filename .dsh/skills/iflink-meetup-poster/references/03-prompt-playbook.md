# 03 · 提示词手册（两档结构 + 修复模板）

## 〇、先定一条：提示词学的是风格，不是排版

这条是踩过坑才定下来的。第一版 Skill 把「左信息 50–55% / 右插画 45–50% / 左基准线 x=54 / 主标题 7.2%」全写进了提示词，
结果每次都长一个样，被一句"太死板了"打回。

**参考图能给的是质感，不是版式。** 质感是：平涂色块、4–5px 黑描边、收口略抖、大留白、荧光绿点睛、干净但不精致。
版式是：谁在左谁在右、插画占几成、嘉宾单列还是网格 —— 这些每期都该能变。

### 两档提示词

| | 自然版（默认） | 规格版 |
| --- | --- | --- |
| 长相 | 像跟设计师口述需求，600–900 字 | 施工规范，3000+ 字，坐标与百分比齐全 |
| 锁什么 | 文字清单 + 配色 + Logo/slogan + 不许加戏 | 以上全部 + 版式位置 + 字号 + 边距 |
| 谁看 | 生图模型（Image 2 / 即梦 / GPT-image） | 渲染器对位、跨期精确复刻 |
| 风险 | 模型可能太放飞 | **必然死板**，且模型可能把参数当正文画进画面 |
| 位置 | `05_提示词_自然版（先试这个）` | `05b_提示词_规格版（要精确复刻时用）` |

`--pack` 只产出一份整合包（md + 三张图）；`build/prompt.md` 里的 ①整版提示词 是规格版原文，仅供渲染器对位参考，不外发。

### 自然版的写作配方（五段）

```
【风格】    学参考图的视觉语言 + 4–6 条可执行的质感描述
【版面】    一句话声明"完全自由"，并列举可选排法（含"反过来也可以"）
【文字】    逐字清单：页眉 / 大标题 / 副标题 / 一句话 / 时间 / 地点 / 嘉宾 / 福利
【画什么】  把嘉宾话题原文列出来，要求从内容里取意象，禁止套固定角色
【硬要求】  三色 + 一点缀色 / Logo&slogan 不重绘 / 一个多余的字都不加
```

结尾固定一句：**按不同排版给我三版海报，三版构图明显不同、画风一致，我挑一版再细调。**
> 注意区别：这里是**一段提示词让模型出 3 版**，不是准备 3 份提示词。后者会让交付物变乱，前者只多几句指令。

### 风格词库（挑 4–6 条写进【风格】段，别全写）

| 维度 | 可用的说法 |
| --- | --- |
| 质感 | 平涂色块 / 马克笔手绘 / 丝网印刷 / 轻微错位感 / 纸面颗粒 |
| 线条 | 4–5px 黑色粗描边 / 收口圆润 / 线条略抖不僵硬 |
| 洁净度 | 干净、利落 / 留白敢留 / 不要塞满 / 不精致但有秩序 |
| 禁止 | 无渐变 / 无光影 / 无 3D / 无照片质感 / 无霓虹赛博 |
| 情绪 | 社区气、像学生社团自己做的 / 有点野但不脏 |

### 别写进自然版的东西（写了就死板）

- 任何位置：左 / 右 / 上 / 下 / 右下角 / 居中偏上
- 任何坐标与百分比：x=54、占 45%、7.2%
- 任何"第 1 行 / 第 2 块"的编号式排版指令
- 固定角色（"必须画一只奶龙"）—— 角色必须从嘉宾话题里长出来

## 一、为什么是三层，不是一段

原对话第一次只用了一段自然语言，结果模型只抓住了"参考这两张图的视觉风格"，把橙红配色、联合主办一起抄了进来。教训：

| 层 | 管什么 | 权重来源 | 写不好会怎样 |
| --- | --- | --- | --- |
| **L1 角色** | 让模型进入"品牌设计师"人格 | 语言先验 | 输出平庸、模板化 |
| **L2 硬约束** | 画布 / 色彩锁 / 版式坐标 / 字体 / 图形语言 | 具体数值 | 风格漂移、跑色、版式散 |
| **L3 内容** | 逐字文案 + 元素白名单 | 显式清单 | 加戏、漏字、写错字 |

`assets/prompt-template.md` 的【① 整版提示词】就是把这三层写成八个板块（画布 → 色彩锁 → 版式骨架 → 字体 → 图形语言 → 文案 → 白名单 → 自检）。

## 二、提示词里的"高杠杆句"

这些句子在原对话里被验证过效果，改版时不要删：

1. **「严格按下面八个板块执行，不得自行增删风格、元素或文案。」** —— 一句话锁住自由度。
2. **「底色奶油白 #F6F6F1，不是纯白 #FFFFFF。」** —— 否命题比正命题有效，模型最爱默认纯白。
3. **「#FE7733 只能当点缀，不许铺成主色。」** —— 点名一个颜色的"用途边界"，比笼统说"用品牌绿"有效；现在橙红是点缀色板之一，禁的是"整版照抄"。
4. **「荧光绿只用于色块、图标、chip、笔刷、涂鸦，禁止用于长段正文。」** —— 防止模型把整段文字刷成绿。
5. **「左基准线 x = 54」这类坐标** —— 具体数字能把"左对齐"落地。
6. **「没有出现在【六、文案】里的任何文字，都不要画上去。」** —— 加戏的终极解药。
7. **「橙红若被铺成大面积或压字，收回成 ≤6% 的点缀或换成荧光绿。」** —— 修复轮专用；橙红本身已解禁，禁的是面积。

## 三、投喂顺序（对 ChatGPT Image 2 实测有效）

```
① 上传 final-poster.png（参考图）
② 上传对应版本的 Logo SVG
③ 补一句：Logo 是定制图形，禁止重绘、改字重、改字距、改色
④ 粘贴【① 整版提示词】
```

原因：图像模型把"附图"当作风格与构图的主锚点，把"文字"当作内容与约束。两者同时给，才不会出现"照抄参考图配色"或"纯文字理解不了笔触"的偏差。

> 如果只有一个上传位，优先给参考图，并把 Logo 作为"页眉位置画一个标准 IF.Link 标识"写进提示词，事后用设计工具替换为真 Logo。**永远不要接受模型重绘的 Logo。**

## 四、修复模板（对应 `assets/prompt-template.md` ②）

| 编号 | 用途 | 触发场闸门 |
| --- | --- | --- |
| ②-a | 通用外壳（任何局部修改都用它开头） | 全部 |
| ②-b | 插画 / 点缀角色修复（**按 spec 自动生成**：有角色按其设定写、没有则改成插画修复） | G5/G6 |
| ②-c | 单行文字修复 | G1，错字漏字 |
| ②-d | 配色回锁 | G2，绿色偏移 / 点缀色超量或跑出板外 |
| ②-e | 字体与版式统一（原作 6 条，验证有效） | G3/G4，整体散 |

### 使用纪律

- **一轮只修一件事。** 同时提 3 个修改点，模型必然顾此失彼（原作 R3 同时改 4 处，结果标题丢字）。
- **每轮都复述"不变"清单。** 句式：`保持……不变，只修改……`。
- **修完立刻重跑闸门**，尤其是 G1（改版最容易把别处文字带崩）。
- **三轮不过就退版本**：回到上一版 PASS 的图继续修，不要在当前这版上叠加修补。

## 五、面向用户的话术模板

### 首轮（拿到散装需求时）

> 我按 6 项必填把信息过了一遍，缺的用默认值补上了：
> 活动名 / 主题行 / 时间 / 地点 / 嘉宾 N 位 / 福利
> 视觉沿用系列定稿：奶油白底 + 荧光绿 #B1FA63 + 深黑灰 #242021，右侧插画，左下福利笔刷。
> 有要改的直接说，没有我就开始装配提示词了。

### 生成后（交付前）

> 已生成。六道闸门结果：
> G1 内容 ✅ / G2 色彩 ✅（66% / 11% / 9%，橙红 0%）/ G3 版式 ✅ / G4 字体 ✅ / G5 图形 ✅ / G6 Logo ✅
> 与参考图的差异：嘉宾姓名改成了本期 4 位；主题行文案不同；其余版式一致。

### 需要用户确认的事实点

> 以下三处请你确认，模型不改就会被永久印在海报上：
> ① 「镣铐」是否为此字（模型常写成「镲锜」）
> ② 陈予谦是男性（头像按男性画）
> ③ 地点「110 室」是否正确

## 六、常见反模式（不要这样写提示词）

| 反模式 | 为什么错 | 改成 |
| --- | --- | --- |
| "参考这张图的风格做一张" | 风格、配色、信息全被抄 | "参考其版式与笔触，配色用 #B1FA63/#242021，内容用下列清单" |
| "高级一点""有设计感" | 无法执行 | "块面直角、无渐变、无投影、单一强调色" |
| "帮我美化一下" | 触发整版重画 | "只调整 X，其余不动" |
| 一次列 5 条修改 | 顾此失彼 | 拆成 5 轮，每轮 1 条 |
| 把品牌规范当附件扔进去 | 模型不读长附件 | 把规范压缩成"色彩锁 + 字体 + 白名单"三段写进提示词 |
| 接受模型给的 Logo | 变形、字重错、不可控 | 只用官方 SVG，事后替换 |
