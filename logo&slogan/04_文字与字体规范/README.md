## 字体清单

- **Logo**：Google Sans Flex（`IF.` 粗体、`Link/Land` 细体，字重与字距已微调，勿自行还原）
- **正文**：Inter Variable
- **代码**：JetBrains Mono
- **中文**：思源黑体（行高修正版）
- **运营标题（仅标题）**：字节技术品牌运营设计字体

## 一句话记忆

> 焦点场景用官方矢量 Logo，正文用系统字体直接打出 `IF.Link`；不衬线、不模拟、不多 Logo 高度不齐。
